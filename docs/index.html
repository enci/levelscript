LevelScript

A scripting language for procedural level design.

Grids and graphs unified into a coherent level, manipulated synchronously with rewrite rules. Compact, expressive and quick, with rules that look like the levels they generate.

Get started GitHub

Live: samples/games/roguelike/roguelike.lvs, seed 42, running in your browser.

Visual patterns

Pattern bodies are drawn as grids. Rotations and reflections are one attribute away, and editors can color cells by tag.

Correlated layers

Terrain, entities, items and numbers live in separate grids that rules read and write together.

Graph layers

Graphs as another view into the same data. Read rooms and halls, label dead ends, hubs and calculate paths intuitively.

Made for games

A small C++ library with zero dependencies. Compiles in a blink on any platform and runs even faster.

Deterministic

Output is a pure function of (seed, params), same everywhere.

Visual debugger

A native that steps through generation one rule application at a time, with breakpoints and playback.

Four main concepts

  1. Tags name the values a cell can hold: tag geo { wall, floor }, compiled to bitmasks for efficient storage and comparison.
  2. Layers are the grids of those tags that make up a level or graphs over the grids, both strongly typed.
  3. Rules match a pattern and rewrite it. Alternatives can be weighted, filtered with where, and run in any rotation.
  4. Sequences orchestrate the work with resize, scatter, everywhere, grow, settle and friends.

Tools

levelscript

Compile a .lvs file, run a sequence with a seed and parameters, and print every layer.

levelscript-debugger

Step, pause, restart and set breakpoints. Per-layer display settings can use text or tilesets.

VS Code extension

Highlighting, diagnostics as you type, hover, go-to-definition, completion and a live AST view. Get it from the Marketplace.

Embed it

Compile a generator once, then ask it for levels:

auto gen   = ls::generator::compile(source, "dungeon.lvs", resolve);  // resolve maps `use` paths
auto level = gen.generate(gen.sequence("main"), seed);
auto geo   = level["level"];
int  wall  = gen.tag("geo.wall");
if (geo.at(x, y) == wall) { /* ... */ }

Install

Installers for Windows and macOS are attached to every release. Both install levelscript and levelscript-debugger and add them to your PATH. Then:

levelscript --seed 42 samples/games/roguelike/roguelike.lvs

Continue with Getting started, browse the samples, or write your own in the lab.
