LevelScript

A scripting language for procedural level generation.

Describe how a stack of grids is rewritten, rule by rule. The output is a pure function of seed and parameters, so every level is reproducible.

Get started Download GitHub

Rules that look like the levels they make

A rule is a pattern on the left and what to write on the right. The cells are laid out as a grid, so you can read a rule the way you would read the map. This is the whole cave generator. It runs live in your browser, so edit it, change the seed or step through it:

Visual patterns

Pattern bodies are drawn as grids. Rotations and reflections are one attribute away, and editors can colour cells by tag.

Correlated layers

Terrain, entities, items and numbers live in separate grids that rules read and write together.

Deterministic

Output is a pure function of (seed, params). Goldens in CI catch any change to the draw sequence.

Graph layers

Read rooms and halls out of a grid as a graph, then label dead ends, hubs and distance from the start.

Step debugger

A native window that steps through generation one rule application at a time, with breakpoints and playback.

Made for games

A small C++ library first and a CLI second. Compile once, then generate with any seed at runtime.

Four ideas

  1. Tags name the values a cell can hold: tag geo { wall, floor }.
  2. Layers are the grids of those tags that make up a level.
  3. Rules match a pattern and rewrite it. Alternatives can be weighted, filtered with where, and run in any rotation.
  4. Sequences orchestrate the work with resize, scatter, everywhere, grow, settle and friends.

Tools

levelscript

Compile a .lvs file, run a sequence with a seed and parameters, and print every layer.

levelscript-debugger

Step, pause, restart and set breakpoints. Per-layer display settings can use text or tilesets.

VS Code extension

Highlighting, diagnostics as you type, hover, go-to-definition, completion and a live AST view. Get it from the Marketplace.

Embed it

Compile a generator once, then ask it for levels:

auto gen   = ls::generator::compile(source, "dungeon.lvs", resolve);  // resolve maps `use` paths
auto level = gen.generate(gen.sequence("main"), seed);
auto geo   = level["level"];
int  wall  = gen.tag("geo.wall");
if (geo.at(x, y) == wall) { /* ... */ }

Install

Installers for Windows and macOS are attached to every release. Both install levelscript and levelscript-debugger and add them to your PATH. Then:

levelscript --seed 42 tests/golden/programs/dungeon.lvs
