Getting started

From install to your first generated level in a few minutes.

1. Install

Download the installer for your platform from the latest release. It installs levelscript and levelscript-debugger and adds them to your PATH, so open a new terminal afterwards.

macOS: the package is unsigned. The first time, allow it under System Settings › Privacy & Security › Open Anyway. Uninstall with sudo /usr/local/levelscript/uninstall.sh.

To build from source, see Build from source.

2. Your first generator

Save this as hello.lvs:

tag geo { wall, floor }

layers {
    level: grid of geo
}

rule fill {
    level[.]
    =>
    level[floor]
}

sequence main {
    resize(8, 4)
    everywhere fill
}

Run it:

levelscript hello.lvs

The output is every layer printed as text, one letter per tag value. . is an empty cell.

  • tag declares the values a cell can hold.
  • layers declares the grids. A level can have several.
  • rule fill matches every empty cell (.) and writes floor.
  • sequence main is the entry point: size the grid, then apply the rule everywhere.

3. Add some randomness

Weighted alternatives pick one outcome per match, driven by the seed. Replace the rule with this one and try a few seeds:

rule fill {
    level[.]
    =>
    { any
      (weight=1) level[wall]
      (weight=3) level[floor]
    }
}
levelscript --seed 1 hello.lvs
levelscript --seed 2 hello.lvs

The same seed always gives the same level. From here, look at cave for cellular automata, rooms for placement with overlap checks, and dungeon for several layers working together.

Command line

levelscript [--seed N] [--entry name] [--param name=value ...] [--inspect] <file.lvs>
levelscript --ast [--no-spans] <file.lvs>
OptionMeaning
--seed NSeed for the run. Omitted, a random seed is used.
--entry nameSequence to run (default main). If it doesn't exist, the available sequences are listed.
--param name=valueSet an integer parameter; repeatable.
--inspectDon't run; print a JSON report (diagnostics, symbols) for editor tooling.
--astDon't run; print the syntax tree with source ranges. --no-spans leaves the ranges out.
levelscript --seed 7 --param difficulty=2 tests/golden/programs/arena.lvs

Compile errors and warnings go to stderr, and a compile error exits with 1. use paths resolve relative to the importing file.

Debugger

levelscript-debugger [--seed N] [--entry name] [file.lvs]

Step through generation one rule application at a time and watch the layers change. Set breakpoints by clicking the gutter next to a statement. Without a file the window opens empty: open a script with the folder button (Ctrl+O, Cmd+O on macOS) or by dropping a .lvs file on the window.

KeyAction
F5Run / continue to the next breakpoint
F6Pause
F10Step over: finish the statement, called sequences included
F11Step into: one rule application
Shift+F11Step out: finish the current sequence
Ctrl+Shift+F5, RRestart
SpaceToggle timed playback
QQuit

Per-layer display settings (text or tileset, opacity, visibility, zoom, background colour) are saved next to the script as <file>.lvs.json.

VS Code

Install the LevelScript extension for syntax highlighting, diagnostics from the compiler as you type, pattern cells coloured by tag value, hover, go-to-definition and completion. LevelScript: Show AST opens the syntax tree beside your file, and another command opens the file in the native debugger.

Embedding in a game

auto gen   = ls::generator::compile(source, "dungeon.lvs", resolve);  // resolve maps `use` paths
auto level = gen.generate(gen.sequence("main"), seed);
auto geo   = level["level"];
int  wall  = gen.tag("geo.wall");
if (geo.at(x, y) == wall) { /* ... */ }

The library compiles a self-contained artifact once and generates from it as often as you like. See Appendix A of the spec for the full API.

Build from source

cmake -S . -B build
cmake --build build --config Debug --parallel
build/tests/Debug/ls_tests.exe
python tools/run_goldens.py

To build the installers yourself, run python packaging/windows/build_installer.py (needs Inno Setup 6.3+) or python packaging/macos/build_pkg.py.
